🚀 COMMANDES PRINCIPALES

# Voir les modes disponibles
python3 preset_manager.py modes

# Générer un nouveau preset
python3 preset_manager.py generate <MODE> [--description "desc"]

# Lister les presets existants
python3 preset_manager.py list [mode]

# Informations détaillées sur un preset
python3 preset_manager.py info <MODE> <VERSION>

# Appliquer un preset
python3 preset_manager.py apply <MODE> <VERSION> [--output "path"]

📈 EXEMPLES D'UTILISATION

Exemple 1 : Préparation GAC
─────────────────────────────
$ python3 preset_manager.py generate GAC_5v5 --description "Semaine 15"
$ python3 preset_manager.py apply GAC_5v5 2025-12-10_v1
→ Charger dans GrandIvory et optimiser

Exemple 2 : Raid Naboo
──────────────────────
$ python3 preset_manager.py generate RAID_NABOO --description "Team Droideka"
$ python3 preset_manager.py apply RAID_NABOO 2025-12-10_v1
→ Optimiser les droids pour dégâts max

Exemple 3 : Configurer Openers
───────────────────────────────
$ python3 preset_manager.py generate FASTEST --description "Thrawn, C-3PO"
$ python3 preset_manager.py apply FASTEST 2025-12-10_v1
→ Cherry-pick uniquement Thrawn et C-3PO

💡 POINTS CLÉS À RETENIR

1. Le fichier .sample est la SOURCE DE VÉRITÉ
   → Toutes les générations partent de cette base
   → Ne pas le supprimer ou corrompre

2. Les versions sont AUTOMATIQUES
   → Pas besoin de gérer manuellement
   → Format: 2025-12-10_v1, v2, v3, etc.

3. Les presets sont ÉDITABLES
   → Modifier le JSON après génération est OK
   → Le versioning reste intact

4. Stratégies PERSONNALISABLES
   → Éditer MODE_STRATEGIES dans preset_manager.py
   → Ajouter de nouveaux modes facilement

5. COMPATIBLE avec tous les outils
   → GrandIvory, HotUtils, C-3PO
   → Format JSON standard
