## 📈 Stratégies Détaillées

### 🏆 Modes PvP - Grand Arena Championship

#### GAC_5v5 & GAC_3v3
**Philosophie :** Jouer en premier = Gagner

```
Priorités :
✓ Speed au MAXIMUM (100)
✓ Dégâts critiques élevés (75)
✓ Chance critique moyenne (50)
✓ Offense physique/spéciale (40)
✗ Défense minimale (survie secondaire)
```

**Archétypes concernés :**
- DPS (Hunters, Sith Empire, etc.)
- Supports (Hermit Yoda, C-3PO)
- Control (Thrawn, Bastila)

**Exception :** Tanks et pretaunters → Utiliser preset TANKY

---

### ⚔️ Modes Raid

#### RAID_NABOO
**Philosophie :** Maximiser dégâts, contrôler Turn Meter

```
Priorités :
✓ Dégâts critiques au MAX (100)
✓ Offense physique/spéciale (75)
✓ Chance critique (75)
✓ Santé/Protection modérées (40-50)
✗ Speed RÉDUIT (25) pour gestion TM
```

**Raison du low speed :** Éviter de dépasser le seuil de TM et perdre des tours.

**Teams principales :**
- Droids (Droideka, B1, B2)
- Jabba's crew
- Gungans

---

#### RAID_KRAYT
**Philosophie :** Potency cruciale pour appliquer debuffs

```
Priorités :
✓ Potency élevée (75) - Debuffs essentiels
✓ Dégâts critiques (80)
✓ Offense (70)
✓ Chance critique (60)
✓ Speed modéré (50)
```

**Debuffs clés :**
- Tenacity Down

## 🔄 Transition Entre Modes

### De GAC vers Raid Naboo

```bash
# Sauvegarder config actuelle GAC
python3 preset_manager.py generate GAC_5v5 --description "Avant switch raid"

# Charger config Raid
python3 preset_manager.py apply RAID_NABOO 2025-12-10_v1

# Optimiser dans l'app
# Appliquer mods in-game
```

**Personnages à re-mod en priorité :**
- Droids (B1, B2, Droideka)
- Jabba crew
- High damage dealers

**Personnages à laisser en GAC :**
- Supports (Hermit, 3PO)
- Control characters (Thrawn)

---

### De TANKY vers FASTEST (pour un personnage)

**Exemple : Thrawn**

1. Identifier le personnage dans le JSON
2. Charger preset FASTEST
3. Appliquer seulement sur Thrawn
4. Réoptimiser

**Astuce :** Vous pouvez avoir plusieurs presets actifs et cherry-pick les bons personnages de chaque.

## 💡 Conseils Stratégiques

### 1. Priorisation des Re-Mods

**Ordre d'importance :**

1. **Openers** (FASTEST) → Impact immédiat sur victoire
2. **Raid teams** → Performance guilde
3. **GAC offense** → Wins personnels
4. **GAC defense** → Deterrence
5. **TB characters** → Contribution guilde

### 2. Allocation des 6-Dot Mods

**Priorité absolue :**
- Speed primary (arrows) → Sur TOUS les DPS/Supports
- Triangle CritDmg → Sur DPS principaux
- Cross Protection/Health → Sur tanks

**Secondaire :**
- Speed secondaries → Distribuer largement
- CritChance/CritDmg → Sur DPS
- Health/Prot % → Sur tanks

### 3. Sets de Mods Recommandés

| Mode | Sets Prioritaires |
|------|-------------------|
| GAC | Speed (×4) / Speed + Crit |
| RAID_NABOO | CritDmg + CritCh / Offense |
| RAID_KRAYT | Potency + Offense |
| TB_ROTE | Health + Defense |
| FASTEST | Speed (×3 sets) |
| TANKY | Health + Defense + Tenacity |
