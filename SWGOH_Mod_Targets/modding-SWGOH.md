# 📁 Organisation des Dossiers de Modding SWGoH

L'organisation de vos mods par mode de jeu vous permet d'appliquer rapidement les "poids" (weights) optimaux dans des outils comme GrandIvory.

## I. Modes PvP (Priorité Vitesse)

| Dossier | Nom Anglais | Description de la Stratégie |
| :--- | :--- | :--- |
| `GAC` | Grand Arena Championship | **Standard : Vitesse maximale.** (Speed 100). |
| `TW` | Territory War | Standard GAC, sauf pour les personnages avec Omicron TW spécifiques. |
| `ARENA` | Squad Arena | Modding de confort ou d'entraînement. |

## II. Modes PvE de Guilde (Raids & TB)

| Dossier | Nom Anglais | Description de la Stratégie |
| :--- | :--- | :--- |
| `RAID_NABOO` | Battle for Naboo Raid | **Focus Dégâts/Santé.** Vitesse souvent réduite pour optimiser le cycle de tour (TM - Turn Meter). |
| `RAID_KRAYT` | Krayt Dragon Raid | Modding spécifique à la mécanique de ce raid. (Potency, Offense). |
| `TB_ROTE` | Rise of the Empire TB | **Focus Survie (Health/Prot/Tenacity).** Pour les missions difficiles. |
| `TB_DS` | Dark Side Geonosis TB | Modding pour les 4/4 des vagues. |
| `TB_LS` | Light Side Hoth/Geo TB | Modding pour les 4/4 des vagues. |

## III. Modes PvE Solo & Spécifiques

| Dossier | Nom Anglais | Description de la Stratégie |
| :--- | :--- | :--- |
| `CONQUEST` | Conquest | Standard GAC (sauf pour certains exploits). |
| `JOURNEY` | Journey Guide / Legendary | Modding temporaire pour atteindre des seuils de déblocage précis. |
| `CHALLENGES` | Galactic Challenges | Modding temporaire pour les défis spécifiques. |
| `REVAMISSION` | Reva Mission (Inquisitors) | **Seuils spécifiques de Potency/Vitesse.** |

## IV. Catégories Générales (Utiles pour le tri)

| Dossier | Nom Anglais | Description de la Stratégie |
| :--- | :--- | :--- |
| `FASTEST` | Fastest Characters | Pour les supports qui doivent jouer en premier absolu (ex: Thrawn, C-3PO, Lando). |
| `TANKY` | Tanks & Support Defenders | Maximisation de Health, Protection, et Defense. Vitesse secondaire. |
| `BENCH` | Unused Roster | Personnages non utilisés, modding minimal pour l'augmentation de la *Galactic Power*. |
